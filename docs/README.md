# Documentação — short-url

Índice da pasta `docs/`. Documentação narrativa pra humanos. A fonte de verdade técnica fica no código e em `.agents/` (regras em `rules/`, domínio em `context/`), com o índice no `AGENTS.md` da raiz.

- `superpowers/PRD.md` — intenção de produto (problema, público, fora de escopo, critério de "pronto"). Estável.
- `superpowers/ADR.md` — log de decisões arquiteturais (`AD-NNN`), append-only.
- `superpowers/specs/` e `superpowers/plans/` — memória do framework SDD, por feature. Fluxo completo em `.agents/rules/spec-workflow.md`.
